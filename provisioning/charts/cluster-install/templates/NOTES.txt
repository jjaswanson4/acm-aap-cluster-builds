Kubeconfig Download (Available After Installation Completes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The cluster kubeconfig will be available once installation completes (typically 30-60 minutes).

Check if installation is complete:

  oc get agentclusterinstall {{ .Values.clusterName }} -n {{ .Values.namespace }} -o jsonpath='{.status.conditions[?(@.type=="Completed")].status}{"\n"}'

Download kubeconfig once ready:

  oc extract secret/{{ .Values.clusterName }}-admin-kubeconfig -n {{ .Values.namespace }} --to=- > {{ .Values.clusterName }}-kubeconfig

Or save to a specific file:

  oc extract secret/{{ .Values.clusterName }}-admin-kubeconfig -n {{ .Values.namespace }} --to=. --confirm

Use the kubeconfig:

  export KUBECONFIG={{ .Values.clusterName }}-kubeconfig
  oc get nodes

Get admin password:

  oc extract secret/{{ .Values.clusterName }}-admin-password -n {{ .Values.namespace }} --to=-

Web Console URL:

  https://console-openshift-console.apps.{{ .Values.clusterName }}.{{ .Values.baseDomain }}

Monitoring Installation Progress
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Check InfraEnv status:
   oc get infraenv {{ .Values.clusterName }} -n {{ .Values.namespace }}

2. Check cluster deployment:
   oc get clusterdeployment {{ .Values.clusterName }} -n {{ .Values.namespace }}

3. Check agent cluster install:
   oc get agentclusterinstall {{ .Values.clusterName }} -n {{ .Values.namespace }}

4. Check baremetal hosts:
   oc get baremetalhosts -n {{ .Values.namespace }}

5. Watch discovered agents:
   oc get agents -n {{ .Values.namespace }}

6. View installation logs:
   oc logs -n multicluster-engine -l app=assisted-service -f

Installation phases:
  1. Namespace and secrets are created
  2. Cluster manifests ConfigMap is created
  3. Main resources are created (BMH, NMStateConfig, ClusterDeployment, etc.)
  4. InfraEnv generates installation ISO (this may take a few minutes)
  5. Nodes boot from ISO and begin installation
  6. Cluster installation completes

For more information, see the chart README.md.
